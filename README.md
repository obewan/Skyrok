# Skyrok

Source code of the SKSE plugin of **Skyrok - A Weather Mod** for Skyrim Special Edition
([Nexus Mods page](https://www.nexusmods.com/skyrimspecialedition/mods/171093)).

The mod itself (textures, sounds, installer) is distributed on Nexus. This repository holds the
plugin, `Skyrok.dll`, its settings files, and the ReShade shader it drives.

## What the plugin does

Skyrok used to change the game by overriding weather, lighting and image space records, which
conflicted with other weather mods. Since version 2.0 the plugin applies the same changes in
memory, once the game has loaded every mod, so they apply to whatever the load order contains.

- **Darker nights.** Multiplies the night colours of every weather.
- **Moonlit nights.** Night darkness follows the moon phase: brighter under a full moon, darker
  on a new moon, less so under clouds, rain or snow.
- **Darker interiors.** Darkens every lighting template and every interior cell by the same
  factors, so all interiors are treated alike.
- **Image space.** One grading for every image space. Saturation is corrected for each image
  space's own tint, so colours are not washed out outdoors or at night.
- **Heavy rain and heavy snow.** Scales the particles of every rainy or snowy weather.
- **In-game menu.** With SKSE Menu Framework installed, every setting can be changed, compared
  with preset buttons, and saved from inside the game.
- **ReShade link.** When ReShade is present, the plugin tells its shaders whether it is raining,
  whether the player is indoors, and whether it is night.

No game record is overridden. The plugin keeps the original values and recomputes from them, so
changing a setting never stacks on a previous change.

## Requirements

To use the plugin:

- [SKSE](https://skse.silverlock.org/)
- [Address Library for SKSE Plugins](https://www.nexusmods.com/skyrimspecialedition/mods/32444)
- Optional: [SKSE Menu Framework](https://www.nexusmods.com/skyrimspecialedition/mods/120352) for the in-game menu
- Optional: [ReShade](https://reshade.me/) with add-on support, for the rain on the lens effect

The plugin is built with CommonLibSSE-NG, which targets Skyrim SE, AE and VR from one binary.
It has only been tested on the author's own setup.

## Settings

Each feature has its own file in `Data\SKSE\Plugins`. A feature whose file is missing starts
disabled; it can still be switched on from the in-game menu and saved.

| File | Feature |
|---|---|
| `Skyrok_Nights.ini` | Night darkness and moonlit nights |
| `Skyrok_Interiors.ini` | Interior darkness |
| `Skyrok_ImageSpace.ini` | Image space grading and eye adaptation |
| `Skyrok_Rain.ini` | Heavy rain |
| `Skyrok_Snow.ini` | Heavy snow |

The presets shipped by the mod's installer are in [`dist`](dist), generated by
[`dist/make_ini.py`](dist/make_ini.py). The same preset values are also written in
`src/plugin.cpp` for the menu's preset buttons: change both together.

In the menu, changes show when the menu is closed, because SKSE Menu Framework pauses the game
while it is open. Set `FreezeTimeOnMenu = false` in `SKSEMenuFramework.ini` to see them live.

## ReShade

A shader reads a value from the plugin by declaring a uniform with a `source` annotation:

```hlsl
uniform float Rain < source = "skyrok_rain"; > = -1.0;
```

| Source | Value |
|---|---|
| `skyrok_rain` | 0 when dry or indoors, about 0.5 in ordinary rain, 1 in a storm; eased over a few seconds |
| `skyrok_interior` | 1 indoors, 0 outdoors |
| `skyrok_night` | 0 by day, 1 at night, in between during sunrise and sunset |

A uniform keeps its default when the plugin is not connected, so a default of `-1` lets a shader
tell "not connected" from "not raining".

[`reshade/Skyrok_RainLens.fx`](reshade/Skyrok_RainLens.fx) is the rain on the lens effect. The
mod's installer puts it in `Data\SKSE\Plugins\Skyrok\Shaders`, and at game start the plugin copies
it to `reshade-shaders\Shaders\Skyrok` next to the game's executable when it is missing there or
older. The version is the `// Version:` comment at the top of the shader: raise it with every
change, or installed copies will not be updated.

## Building

You need:

- Visual Studio 2022 or newer, or its Build Tools, with the C++ workload
- CMake 3.21 or newer
- [vcpkg](https://github.com/microsoft/vcpkg), with the `VCPKG_ROOT` environment variable set

Then run `build.cmd`, or from a Visual Studio developer prompt:

```
cmake --preset release
cmake --build build\release
```

The result is `build\release\Skyrok.dll`. The first configure downloads and builds the
dependencies and takes several minutes; later builds are quick.

CommonLibSSE-NG is built from the maintained fork by alandtse through the vcpkg port in
[`cmake/ports`](cmake/ports).

## Layout

| Path | Content |
|---|---|
| `src/plugin.cpp` | The features and the in-game menu |
| `src/ReShadeLink.cpp` | Game state published to ReShade |
| `include/Settings.h` | Reading and writing the settings files |
| `include/SKSEMenuFramework.h` | SDK header of SKSE Menu Framework (third party) |
| `include/reshade` | ReShade add-on API headers (third party) |
| `dist` | Preset settings files and their generator |
| `reshade` | The ReShade shader |
